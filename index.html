Event rules

Rules explain what should create an event. In this prototype, rules are examples; a production system would execute them against validated ERP data.

A proper event engine should record the triggering transaction, rule version, evaluation time, threshold, source system and evidence references. This HTML shows the rule catalogue only; it does not monitor ERP changes automatically.
